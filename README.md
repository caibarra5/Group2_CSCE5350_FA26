## Inventory Management System
---
**Description:** Upon completion, this project will act as a database for a retailer to keep track of inventory, shipments, and customer orders. It is meant to streamline a businesses inventory making it easier and more straightforward for the owners to know where their stock is, where it's going, and when it is arriving.  
**Users:** Store Owners, Stock Managers
